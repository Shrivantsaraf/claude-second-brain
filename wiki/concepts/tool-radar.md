# Tool Radar

**One-liner:** Living watchlist of agentic-AI tools worth your time, each with a verdict
tied to your goals (**learn [[agentic-ai]] → personal brand → freelance**). Beginner-friendly +
low/zero cost rank higher.

> Pulled on demand (e.g. "what should I build today?", "what's new worth my time?"). Refresh via
> web search and update this page. Last refreshed: 2026-06-06.

## Current stack (what the user uses today)
- **[[claude-code]]** — primary; the brain + agent builder. Pro/Team plan (flat fee). KEEP.
- **Claude Cowork** — desktop agent surface. Exploring.
- **[[wat-framework]]** — your own Workflows/Agents/Tools pattern. House style. KEEP.
- **[[mcp]]** (Gmail, Calendar, Drive) — how agents reach real services. Lean into more.
- **Claude skills** (humanizer, etc.) + plugins (superpowers v5.1.0, ui-ux-pro-max v2.5.0).

## New / notable (June 2026) — verdict
| Tool | What it is | Verdict |
|---|---|---|
| **[[n8n]]** | Open-source, self-hostable, VISUAL agent/workflow builder (1,800+ nodes) | ⭐ HIGH. Free self-host; visual = great to learn + big freelance market. **Try next.** |
| **n8n-MCP** (czlonkowski) | MCP server so Claude Code can BUILD n8n workflows | ⭐ HIGH. Combines your two best tools. Free. |
| **Claude Agent SDK** | Anthropic's official SDK powering Claude Code (tools, hooks, MCP, subagents) | ⭐ HIGH (later). Production-grade; best for "real" freelance deliverables. |
| **CrewAI** | Role-based multi-agent framework (MIT, free) | 🟡 MEDIUM. Good for multi-agent demos. Python. Worth a weekend. |
| **LangGraph** | Graph-based agent control (free tier) | 🟡 MEDIUM. More advanced; revisit after fundamentals. |
| **Gumloop** | No-code, NL agent builder + MCP | 🟡 MEDIUM. Fast to demo; has paid tiers — mind the zero-cost rule. |

## How to use this radar
- Default to **free / open-source / on-the-Pro-plan** (zero-cost rule).
- For the **brand**: building with a *hot* tool (n8n, Agent SDK) = better content + freelance inbound.
- He can say "what's new worth my time?" → web-search and update this table.
